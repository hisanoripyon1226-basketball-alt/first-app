# 🧪 理科クラフト3D (Science Craft 3D)

**小学校の理科 × 3Dボクセル（Minecraft風）学習アクションゲーム (MVP)**

ブラウザ（Three.js + Web Audio API）で手軽に遊べる3D理科学習アプリです。小学校3〜6年の理科の学習内容（物理・化学・生物・地学）をゲームメカニクスに落とし込み、敵の弱点を見極めて戦いながら理科の法則を楽しく学べます。

🎮 **公開URL (GitHub Pages)**:  
👉 **https://hisanoripyon1226-basketball-alt.github.io/first-app/**

---

## 🌟 特徴

1. **3Dマインクラフト風ボクセルワールド**
   - Three.jsを用いた立方体ブロックで構成される3Dワールド。
   - 草・土・石・木ブロックの破壊（採掘）と設置（建築）が可能。
   - 外部画像不要のプロシージャルテクスチャ生成で即座に高速起動。

2. **オリジナル敵モブ 3体（リアルタイム頭上HPバー付き）**
   - 🔴 **マグマ・ゴーレム (近接突進型 / 地学・熱)**
     - 溶岩と玄武岩の巨体でプレイヤーに突進して殴打。
     - **理科的弱点**: 「冷却凍結」に弱い（急激に冷やすと固まる火成岩の性質）。
   - 🔵 **エレキ・ファントム (遠距離射撃型 / 物理・電気)**
     - 空中を浮遊しながらプラズマ電撃弾を放つ怪鳥。
     - **理科的弱点**: 「電磁石レールボルト」による電磁誘導過負荷に弱い。
   - 🟡 **水素ボマー (自爆特攻型 / 化学・気体)**
     - プレイヤー接近時に「3, 2, 1...」と点滅膨張し、激しい水素爆発を起こす。
     - **理科的弱点**: 「pH中和スプレッダー」で化学的に中和することで爆発を阻止・大ダメージ。

3. **小学校理科を網羅する理科アイテム**
   - 🔍 **凸レンズ集光ビーム (小3 光の性質)**: 太陽光を集めて熱エネルギーに変換し照射。
   - ⚡ **電磁石レールボルト (小5 電磁石・小3 磁石)**: コイルと電流の力で金属弾を超連射。
   - 🧪 **pH中和スプレッダー (小6 水溶液の性質)**: 酸とアルカリの中和反応で大爆発。
   - ❄️ **状態変化フリーザー (小4 もののあたたまり方・水の三態)**: 熱を奪って敵を氷結（固化）。
   - 🌱 **光合成ロッド (小6 植物の養分・日光)**: 二酸化炭素と光から養分を作りHP回復。

4. **学習効果を高める仕組み**
   - **実験ボーナスクイズ**: バトル中に挑戦可能。小3〜小6の指導要領に準拠した良問を多数収録。正解すると全画面必殺技「超理科バースト」が発動！
   - **理科大図鑑**: 各アイテムや現象に対応した分かりやすい科学解説をいつでも閲覧可能。

## 🕹️ 操作方法 (PC)

| キー / 操作 | アクション |
| :--- | :--- |
| **W, A, S, D** | 前後左右に移動 |
| **マウス移動** | 視点移動 (周囲を見渡す) |
| **SPACE** | ジャンプ |
| **左クリック** | 選択アイテムの発射 / ブロック採掘 |
| **右クリック** | ブロック設置 (6, 7番スロット時) / 実験台操作 |
| **数字キー 1〜7** | アイテムスロット切り替え |

※ スマートフォン・タブレットでは画面内のバーチャル十字キーと発射・ジャンプボタンでプレイできます。
